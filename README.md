# Bachelor's Thesis

> **Note:** this thesis is written in **Italian**.

## Integration of the Corporate Chatbot into Microsoft Teams and WhatsApp Business

Bachelor's Degree in Computer Science  
University of Milano-Bicocca  
Academic Year 2024–2025

**Author:** Nicholas Guido Boidi

This repository contains the PDF of my Bachelor's thesis.

The thesis presents the design and development of a middleware layer for integrating a corporate AI-based chatbot with external messaging platforms, including Microsoft Teams, Slack, and WhatsApp Business.

### Topics

- Multichannel chatbot integration
- REST API-based middleware
- Microsoft Teams integration
- Slack integration
- WhatsApp Business integration
- Authentication, state management, and testing

### Tech stack

- NestJS
- Node.js
- TypeScript
- Redis
- Microsoft Azure
- Microsoft Bot Framework
